# げんばログ 1.5.0

Delta Chatのチャットで、日々の出来事や作業を文章・写真・数値で記録し、メンバーと共有するwebxdcミニアプリです。現場日誌、農業日誌、飼育日誌、点検巡回、観察記録、日記の6形式を選べます。

## まず使ってみる

1. Delta Chatで、共有する相手やグループのチャットを開きます。
2. `genba-log-1_5_0.xdc` を添付して送ります。
3. 添付ファイルからアプリを開きます。メンバーも同じ添付を使います。
4. 「書く」で日付・天気・必要な項目・本文・写真を入力し、「投稿する」を押します。
5. 「一覧」に記録が表示されたことを確認します。

送信中は完了まで開いたまま待ちます。画面が長いときは上下にスクロールしてください。

## ファイルの案内

|ファイル|使い方|
|---|---|
|[genba-log-1_5_0.xdc](genba-log-1.5.0.xdc)|Delta Chatで共有して使うアプリ本体|
|[操作マニュアル HTML](genba-log.html)|ブラウザーで読む画面図付きの詳しい手順。画像はHTML内蔵|
|[ブラウザデモ.html](genba-log-demo.html)|アプリの表示・操作をブラウザーだけで確認するテスト用HTML|

**操作マニュアルのHTMLと、アプリ本体の `index.html` は別のファイルです。** `index.html` を通常のブラウザーで開いたテスト投稿はチャットに共有されず、再読み込みすると消えます。実際の共有にはDelta Chatで `.xdc` を開きます。

## できること

- 日付・天気・文章・写真と、用途に応じた数値や選択項目を記録。
- 自分の記録の編集・削除、一覧の写真の拡大表示。
- 点検での未確認項目や要対応記録の絞り込み。
- 月別・全期間での書き出しと、数値の推移グラフ。
- JSONによる記録・写真・形式の引き継ぎ。
- 小学生・中高生・一般・シニア向け、仕事・用途別の表現切替。
- 保存・編集・削除ボタンと本文見出しの独自指定。
- 15の言語選択。FilipinoとTagalogは共通の翻訳を使用。

## 設定の違い

|自分の画面だけの設定|チャット全員に反映される設定|
|---|---|
|言語、年代、仕事・用途、独自の表現|日誌の形式、入力項目、取り込み時の形式変更|

「設定 → 表現の設定」はこの端末・ブラウザーに保存され、記録の中身を変えません。別端末では改めて選びます。

入力項目を変える場合は「日誌の形式」で選び、内容を確認して「全員に反映する」を押します。形式を選ぶだけでは共有設定は変わりません。形式の変更で、過去の記録の一部項目が一覧やCSVに表示されなくなる場合があります。変更前にJSONで保管してください。

## 夏休み日記にする例

1. 表現を「小学生向け」「日記・学校生活」にします。
2. 下の「日誌の形式」で「日記」を選び、「全員に反映する」を押します。
3. 日付・天気・今日のできごと・写真を残します。

表現を変える操作と、人数などの入力項目を変える操作は別です。

## 保管と移行

|形式|主な用途|写真|アプリへの再取り込み|
|---|---|---|---|
|CSV|表計算での集計|枚数のみ|不可|
|HTML|写真付きで読む・印刷する|画像付き|不可|
|JSON|バックアップ・引き継ぎ|画像データ付き|可能|

大切な記録は「データ」で「全期間」を選び、JSONを定期的に書き出して保存します。書き出し後はDelta Chat側の画面で送信先やファイルを確認してください。

新版の `.xdc` を開いても、旧版の記録は自動では移りません。旧版で書き出したJSONを新版の「取り込み」で選びます。「形式も取り込む」を選ぶと、移行先チャット全員の形式も変更されます。

取り込みは元の投稿者IDを保持します。別のアプリに移すと、元の本人でも過去の記録の編集・削除ボタンが出ない場合があります。同じアプリ内で削除した記録は、同じIDのJSONを取り込んでも復活しません。

## 主な上限と注意点

- 1件につき本文500文字、写真3枚。絵文字などは表示上の1文字が複数カウントされる場合があります。
- 追加できる入力項目は6個。選択肢・チェックリストは1項目につき8個まで。
- 写真は送信用にJPEGへ変換・縮小されます。原本の保管は端末側でも行ってください。
- 写真の受信が終わるまで、その記録の編集・書き出しは待ちます。
- 削除は赤い確認ボタンを約3秒以内にもう一度押して確定します。アプリ内に取り消しボタンはありません。
- 未投稿の下書きは、閉じたり読み込み直したりすると失われることがあります。
- 数値の推移グラフには、選択した項目の数値入り記録が対象期間に2件以上必要です。
